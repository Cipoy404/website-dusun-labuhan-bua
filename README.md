# Website Dusun Labuhan Bua

Website statis multi-halaman untuk informasi masyarakat dan promosi potensi lokal.

## Menjalankan lokal

Gunakan ekstensi Live Server di Visual Studio Code, atau jalankan `python -m http.server 8000` dari folder proyek.

## Memperbarui data

- Identitas, kontak, statistik, dan koordinat: `assets/data/site-config.js`
- Berita: `assets/data/berita.js`
- Galeri: `assets/data/galeri.js`

Data yang belum diverifikasi sengaja ditampilkan sebagai kosong atau contoh. Visual hero adalah ilustrasi AI dan harus diganti dokumentasi resmi ketika tersedia.
